# Smart Planner Hub

A productivity application designed to help users manage tasks, organize schedules, track deadlines, take notes, and monitor study progress through a single user-friendly platform.

### Tech Stack

* React.js
* JavaScript
* HTML
* CSS
* Node.js
* MongoDB

## Login & Registration

Smart Planner Hub includes a simple authentication system that allows users to create an account and securely log in using their email and password. The interface also provides password recovery and account navigation options.

![Login and Registration](https://github.com/user-attachments/assets/dec73dd9-bce7-4f2a-a77f-3abaf395d402)

## Project Modules

The application integrates multiple productivity modules:

* **Dashboard** – Provides an overview of tasks and productivity activities.
* **Notes** – Allows users to create and manage personal notes.
* **Task Manager** – Helps users create, organize, and track tasks.
* **Pomodoro Timer** – Supports focused study and work sessions.
* **Calendar** – Helps users plan schedules and important dates.
* **Study Tracker** – Tracks study activities and progress.

![Project Modules](https://github.com/user-attachments/assets/870c7de2-227a-4b4f-80a1-24acee331740)

## Features

* User registration and login
* Task management
* Daily scheduling
* Calendar planning
* Notes management
* Pomodoro focus timer
* Study progress tracking
* Deadline and reminder management

## Project Objective

The main objective of Smart Planner Hub is to provide students and users with a centralized platform for managing their daily tasks, schedules, notes, and study activities, helping them organize their priorities and manage their time effectively.
